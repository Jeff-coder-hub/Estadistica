Este repositorio contiene las prácticas desarrolladas para el curso Sistematización de Métodos Estadísticos, incluyendo los archivos .qmd generados y ejecutados en RStudio. Aquí se documenta el proceso completo de creación del proyecto, desde la configuración del entorno local hasta la vinculación del repositorio remoto en GitHub mediante Git. Cada carpeta y archivo refleja las actividades trabajadas en clase, con un enfoque en la reproducibilidad, la organización y el control de versiones. El repositorio permite visualizar el código fuente, los resultados obtenidos y el historial de cambios realizado por el grupo durante el desarrollo de la práctica.
